# 回答建議氣泡前端契約（待後端接入）

2026-11-06，本機預覽；未部署。

SSE completed 事件與歷史 turns 每項均可提供 `suggested_questions: string[]`。前端依每則回答的陣列逐項顯示，數量不固定；字串以純文字呈現，自動換行。空白／非字串項忽略，相同文字去重。

- 未提供欄位：暫時顯示「怎样辨认控制行为」「帮我梳理一下」兩項佔位建議。
- `[]`：不顯示任何建議，避免以佔位內容覆蓋後端的明確空結果。
- 有效陣列：取代佔位建議，附於該則回答的複製／評價操作下方。
- 生成中不顯示佔位建議；點擊填入草稿，需手動發送。
- 此次只接前端；後端欄位名稱／產生邏輯仍須雙方對齊，沒有宣稱後端已傳送。

範例：`{"suggested_questions":["我可以怎樣保留證據？","幫我整理剛才的經歷"]}`。

版面：正文 14px、1.4 倍行高；歷史列操作高度40px、相鄰列無額外間距。側欄以可用高度為界，歷史列表捲動，帳號與版權保留在框內。
