# 已確認 Chat 設計的正式元件實作

2026-11-05。本輪已實作於本機正式 React 元件，尚未提交、推送或部署。使用者選擇不新增 shadcn 套件，以現有 React、CSS 與聊天狀態實現確認稿外觀與分區；套件清單和鎖檔未修改。

## 完成內容

- 72px 頂欄保留現用頭像／品牌、可收合工具與獨立快速離開；工具中移除新對話。
- 歷史與帳號放在側欄，桌面預設展開、手機以原生模態抽屜顯示。桌面點主聊天區收合，手機點抽屜外側背景關閉，Esc 與焦點返回沿用。
- 對話中央保留訊息與操作、狀態及錯誤恢復；底部輸入使用獨立佈局列，透過 portal 保持原 Chat 草稿／語音狀態，避免 fixed 元件蓋住恢復入口。主區點擊收合排除來自 portal 輸入區的事件。
- 新聊天放大現用頭像；四個建議使用桌面置中／手機等寬短膠囊。點擊文字題目填入草稿、支持資源開面板，沒有自動發送。對話中的小膠囊保留。
- 輸入框預設約 58px，文字、麥克風、送出／停止同列；長文字可增至五行。移除可見標籤與輸入選項，保留無障礙名稱、組字及鍵盤保護。
- 語音統一按住說話、鬆開轉文字，先入草稿再手動發送；支援 Space／Enter 按住鬆開，取消與背景釋放沿用。首次授權只準備設備，語音保存告知在首次說明及工具設定中仍可到達。
- 保存及隱私狀態改在同一隱私 dialog 管理，入口位於帳號區；資源預設關閉，新增安全包卡片，輸入框下也保留安全包入口。

## 驗證

- 136 項單元／回歸測試通過；TypeScript 與修改的 TS／TSX ESLint、git diff --check 通過。
- 10 組可控 API 的聊天瀏覽器回歸通過：正常回覆、延後危機提示與焦點、持續危機去重、恢復 normal 後再次提示、停止與遲到結果、失敗恢復、歷史選取／刪除、隱私、窄螢幕與退出。無頁面 JavaScript 錯誤。
- 新版面專項通過：桌面／手機、320px 四膠囊同列與文字無溢出、58px 輸入框、草稿不自動發送、歷史點擊回縮／抽屜背景關閉。
- Chrome 權限拒絕與合成麥克風按住／鬆開錄音轉寫通過；不使用實體麥克風。發現並修復啟動錄音時 disabled 導致鍵盤焦點丟失。
- 本機磁碟反覆 ENOSPC，後改用不寫 webpack cache 的暫時開發啟動方式完成驗證；正式 next.config.js 未改。本輪未做完整 production build 或真機讀屏／手機驗收。
