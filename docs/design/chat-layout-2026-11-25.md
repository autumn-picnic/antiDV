# Chat 页面排版与历史标题

已按确认的示意图完成本地实现。页面保留小安配色、原头像和三句开场白，顶部使用米白底色；六个话题气泡为两列三行、白底、浅色细边框、左对齐文字，不显示箭头。

历史对话和支持资源通过顶部按钮分别展开左右抽屉，默认完全收起，不占用聊天区域。再次点击按钮、关闭按钮或面板外部可关闭；两个抽屉互斥。快速退出组件及其原有跳转、清理和 ESC 行为没有改动。调试开关放在输入框下方，仍可在首轮发送前启用。

隐私入口显示「隐私说明」，打开现有「隐私与保存」弹窗。保存期限、授权、错误提示和状态读取继续使用现有逻辑；说明文字移入弹窗。注册／登录保留游客菜单和已有自愿授权流程。

## 历史标题

原实现以会话 ID 前八位作为标题。新版本遵循修改后的小模型方案：首轮成功保存后，服务器从已授权、脱敏的首条记录生成最多 24 字的语义标题，并关联来源 response ID 保存。模型生成与继续聊天并行；失败时使用原句提取标题，不中断聊天。

刷新和打开历史列表只读取模型标题，不为旧会话批量生成。没有模型标题时读取首个仍保留轮次并作原句回退。保留用户否定和不确定性，不新增身份信息。具体来源、租约、期限和删除约束见 `../conversation-title-model.md`。

## 与线上 main 整合

发布基于当前 main，保留停止回复、失败记录、屏幕阅读器状态、语音输入、游客授权及管理员调试控制。新抽屉使用 Escape 先关闭面板，保持原版全局快速退出按键规则。
