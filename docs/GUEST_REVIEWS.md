# 游客评分与反馈

回答完成后，气泡右上角常驻星形评分按钮；生成过程中隐藏。游客与登录用户都可提交 1–5 分及最多 500 字建议，同一回答再次评价会更新原记录。

浏览器通过 `/v1/reviews` 读写评价，使 Path=/v1 的 HttpOnly 游客 Cookie 正常随请求发送。旧 `/api/reviews` 保留为兼容入口。游客必须持有有效会话凭证；无凭证返回 401，不属于该游客或过期的会话被拒绝。

服务端先通过现有后端会话接口验证游客凭证及 conversation ID；验证失败或后端不可用时不会读取/写入评价数据库。随后 SQL 再核对回答属于该会话、会话尚未被认领且未过期。已登录身份继续走原有账号归属检查，失效的 Clerk 会话不会降级为游客。

继续使用 `xiaoan_answer_feedback`，不新增表或权限。游客评价的现有 `clerk_user_id` 字段存 `guest:<conversationId>` 标记，不保存游客原始凭证。账号评价仍保存 Clerk user ID。管理员读取权限维持指定已验证主邮箱及 admin 角色要求。

验证覆盖游客凭证缺失/错误、后端故障、会话 ID 不匹配、参数化写入与过期条件；组件渲染测试覆盖常驻原生按钮、生成中隐藏和已评价后的修改入口。
