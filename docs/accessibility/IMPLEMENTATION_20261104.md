## 已實作

- 退出採暖淺底深棕字、44px 高度及固定右側空間；移除拖曳。2026-11-05 依使用者要求移除按鈕下方退出／Esc 說明。Esc 尊重組字、已消耗事件、按鍵重複及原生 dialog；設定與彈窗先關閉。
- 共用原生 dialog hook 隔離 Esc、使用瀏覽器焦點限制並返回觸發者；手機歷史／資源改用模態介面。評分、語音說明等彈窗提供快速退出。
- 危機彈窗元件改為「继续聊天」、Esc 回聊天，聊天保留安全包入口。2026-11-05 依使用者確認將危機提示接入主頁，僅由本次正式完成事件觸發。
- 共用 Button、歷史選取及回答操作改為原生按鈕。歷史切換與刪除分開，標示目前對話；訊息使用 article 與發話者／序號標題，操作名稱可區分。
- 加入跳至內容／輸入框、可見輸入標籤、組字保護、最新回答定位、依閱讀位置跟隨捲動。資源維持穩定 DOM 順序，依內容突出相關項目。
- Hook 明確輸出每次請求的 sending／completed／stopped／failed 事件；獨立狀態通知預設不播全文，設定可啟用當前分頁全文通知。遲到事件不誤報完成；重要錯誤持續顯示。
- 停止／失敗時可另外閱讀未完成文字，不混入已提交歷史或匯出。此文字只是當前操作的暫存預覽，切換對話或開始新操作後不保留。
- 預設點按錄音，可切換按住；首次說明與授權只準備裝置，需再次操作才開始錄音。兩種模式共用 hook；取消與背景／退出釋放裝置，遲到轉寫不回填。轉寫後維持手動發送，僅在使用者仍位於輸入區時移焦回輸入框。
- 加入全域焦點、減少動態偏好、較大文字與控制範圍。歡迎頁、窄螢幕及低高度畫面的輸入區採內容流，避免固定輸入區遮住正文。

## 尚待驗收

2026-11-05 危機彈窗補充：加入明確的 `position: fixed; inset: 0; margin: auto`，最大高度 90dvh，內容過長可捲動。使用已安裝 Chrome，以專案置中 CSS 及包含相同文字的獨立 dialog 樣例量測 1440×900、390×844、320×480，水平與垂直中心誤差均為 0px，且在視窗範圍內。此為樣式驗證；主頁觸發已接入，完整瀏覽器流程仍待驗收。

危機觸發規則（2026-11-05 使用者確認並已實作）：

- 只採用當前對話本次請求成功完成後的正式 `safety_level`；`immediate_danger` 或 `self_harm` 可觸發。`normal`、`unclear`、歷史載入、停止、失敗及過期請求均不觸發；不從文字關鍵詞或 debug 推斷。
- 以 response_id 去重。同一對話危機持續期間只自動提示一次；繼續聊天、Esc 或查看安全包皆算本次提示已處理，不改寫安全判定。當後續新回覆明確為 normal 後，可在再次進入危機時提示；unclear 不重置。
- 有其他彈窗時不疊加，暫存至其關閉；切換對話、退出或較新結果已解除危機時取消待提示，並檢查最新對話與請求身份。
- 展示時聚焦「继续聊天」，關閉後回到聊天合理焦點；保留常駐安全包入口。等待完成事件會延後提示至回答結束；若要更早提示，需後端新增正式 safety 事件，另行設計。

- 真實麥克風允許／拒絕、錄音品質與手機背景切換；本輪未使用私人麥克風。
- 天坦、保益、爭渡、VoiceOver、NVDA、TalkBack 的實際播報與手勢；程式及無障礙樹檢查不取代真機結果。
- 連接正常後端後的實際串流、全文通知、歷史切換／刪除與保存後焦點。
- 200% 文字、400% 縮放、文字間距及 iOS／Android 軟鍵盤實機驗收。
- 危機元件已掛載主頁；正式後端危機回覆、其他彈窗延後顯示及讀屏焦點的完整瀏覽器流程仍待驗收。
- 完整 production build／E2E 未執行，依專案規則需另獲授權。未 git push、未發布。
