# 無障礙與危機提示發布驗證

日期：2026-11-05。PR：<https://github.com/autumn-picnic/antiDV/pull/22>。

本次改動改善聊天鍵盤操作、回覆通知、點按錄音、模態焦點與危機提示，並移除快速退出下方的說明。危機提示僅由本次完成回覆的正式安全標記觸發，不重放歷史，也不把關閉提示記錄成使用者已安全。

## 驗證結果

- 136 項單元／回歸測試通過。加入缺漏的失敗回報模擬，並擴充 PR CI 至所有測試。
- 聊天 TypeScript 及本次 TS／TSX ESLint 檢查通過。
- 初次 production build 完成；後續一次因本機磁碟空間不足而在 standalone 打包中止，空間回復後已重新完成建置。Next 內建 ESLint 仍回報既有 flat-config 整合選項不相容；獨立 ESLint 與 CI Lint 分開驗證。
- production 頁面 10 組瀏覽器情境通過：一般回覆、選單延後危機提示、彈窗置中與「继续聊天」初始焦點、Esc 回聊天、危機去重及重新啟用、停止後忽略遲到結果、失敗恢復、歷史選取／確認刪除、隱私視窗、320／390px 輸入與無頁面橫向溢出、快速離開流程。未出現頁面 JavaScript 錯誤。
- Chrome 實際權限拒絕路徑可顯示說明且繼續文字輸入。合成麥克風測試通過首次授權不錄音、點按開始／結束、轉寫只進草稿而不自動送出；未使用實體麥克風或私人音訊。
- 現有 Azure 真實後端：以合成招呼訊息建立訪客會話（201），回覆串流（200）包含 start、delta、completed。前端的停止、失敗與危機狀態測試使用可控的合成 API 回覆。
- 驗收修復了原生 dialog 開窗後焦點落在快速離開、訪客缺少隱私入口、聊天最小高度把錯誤恢復操作推入固定輸入區下方三項問題。

## 人工驗收待辦

以下需要實際裝置或使用者，仍列為待驗收：

- 天坦、保益、爭渡、NVDA、VoiceOver、TalkBack 的真實播報、手勢與焦點返回。
- iOS／Android 實體麥克風品質、背景切換、系統權限與軟鍵盤遮擋。
- 真實瀏覽器 200% 文字、400% 縮放與使用者文字間距設定。320px 視窗檢查已有結果，縮放操作本身仍需另驗。
- 帳號登入後隱私保存變更及實際保存後焦點；本輪瀏覽器流程使用訪客與合成資料。

這些項目尚未取得實際相容性結果；目前可支持程式、合成互動及已列出的連線驗證結果。
